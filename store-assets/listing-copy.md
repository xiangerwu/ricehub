# Chrome Web Store Listing Copy

## English

**Name:** RiceHub

**Summary:** Prepare a configurable GitHub repository analysis prompt and open it in your chosen AI agent.

**Single purpose:** RiceHub prepares an analysis prompt for the GitHub repository currently being viewed and opens that prompt in a user-selected desktop agent or HTTPS destination.

## 繁體中文

**名稱：** RiceHub

**摘要：** 為目前的 GitHub 儲存庫準備可自訂的分析提示詞，並在你選擇的 AI 代理中開啟。

**單一用途：** RiceHub 針對目前瀏覽的 GitHub 儲存庫準備分析提示詞，並在使用者選擇的桌面代理或 HTTPS 目的地開啟。

## Review and Privacy Fields

**Storage permission:** Saves the selected destination, language, analysis sections, per-section instructions, button appearance, and button position in local extension storage. It does not store repository URLs, generated prompts, or analysis results.

**Remote code:** No. All executable code is included in the submitted package.

**Data handling:** RiceHub reads the current GitHub repository URL and page title and combines them with the user's saved settings. Only after the user clicks the floating button, the resulting prompt is passed to the destination selected by the user: Claude Desktop, Codex Desktop, or a user-configured HTTPS URL. RiceHub has no developer-operated server, analytics, advertising, or sale of data.
