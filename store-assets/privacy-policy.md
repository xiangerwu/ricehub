# RiceHub Privacy Policy

Effective date: August 4, 2026

RiceHub prepares a repository-analysis prompt locally in the browser. It reads the URL and title of the GitHub repository page being viewed and combines them with settings and instructions supplied by the user.

RiceHub sends nothing when the page loads. When the user clicks the RiceHub button, the prepared prompt is passed to the destination the user selected: Claude Desktop, Codex Desktop, or a user-configured HTTPS URL. That destination processes the prompt under its own terms and privacy policy.

RiceHub stores only configuration in the browser's local extension storage: destination, language, analysis sections, custom instructions, button appearance, and button position. It does not store repository URLs, generated prompts, or analysis results. Removing the extension removes this local configuration according to the browser's extension-storage behavior.

RiceHub has no developer-operated server, analytics, advertising, or sale of user data. It does not execute remote code.

Questions or deletion requests: <https://github.com/xiangerwu>.
